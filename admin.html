部门维度权限设置（iOA 统一登录）

权限模型：系统管理员 = 全部配置 + 全看板读写；其余账号按角色（HRBP / 招聘经理 / 业务）定各看板默认权限，可再由「看板权限」列按 看板1-4 单独微调「编辑 / 查阅 / 无」；权限按部门空间隔离，同一账号可归属多个部门。带 示例 的为演示行，正式版从 iOA 组织架构同步。
正式版：输入 iOA 账号自动带出姓名/部门；BP 名单与部门权限由 iOA 关系链读取识别。

线维权限设置（iOA 统一登录）

层级规则：线级是一级层级，部门是二级层级——但线与部门的父子关系并非既定，只有创建线级看板后才产生。未被创建进任何线级看板的部门仍为一级层级，且不出现在层级预览里。建立几个线级板块，层级预览就出现几个线级。改动即时同步到看板端顶层的线导航（coby线/wang线…）。
从部门清单里勾选若干部门并命名，即生成一条线级看板；线内部门降为二级。
线级 / 账号设置线级看板操作
层级预览在「设置线级看板」弹窗里（点行/⚙ 打开）——线级=一级、线内部门=二级，父级可收起。

项目配置（看板1 指标行）

项目名称可直接点击修改（改名只改显示口径，不动取数逻辑）。 可手动添加：开 = 该项目下允许 BP「⊕ 新增分支」（自定义命名·选＋/−）；关 = 只读系统数。 前期数据解绑：开 = 对该项目的定义变更（改名/换源/停用）不回溯已发生月——前期数据按原口径封存在历史快照；关 = 变更联动刷新全部历史。 数据源未接入的项目取数为空（绝不编造）。
新增的项目会出现在看板1 对应分区，初始无数据（留空待接源/待 BP 录入）。

搜索并选择账号即可添加（iOA 账号自动带出姓名）；也可直接输入新账号。可不归属部门直接添加。选一个主角色定其默认看板权限。

角色 ·

选一个角色，即采用其默认看板权限（可再用⚙微调）：HRBP=看板1/2/3/4编辑、招聘经理=看板3编辑·其余查阅、业务=看板1/2/3/4查看。

指定线级BP ·

从所有已注册账号中选择（按部门结构查找，与部门无关也可加入），加入即为本线级 BP、可看本线级板块。

部门权限配置 ·

看板1可见部门=该账号能在看板1切换/编辑的部门；看板0(PM速览)可见部门=PM速览里聚合展示的部门。二者独立——可"看板1能看、看板0不展示"。

设置子PM看板（分组与层级）

从该部门下的中心里选择若干中心，命名后创建子PM看板组。建组后：组为二级层级，组内中心降为三级；未进组的中心仍为二级。
